## PDF

您可以 [在线查看](https://rogeryoungh.github.io/math-notes)。旧版 LaTeX 可以去 [Release](https://github.com/rogeryoungh/math-notes/releases/tag/latest) 下载，不再维护。

Typst 代码在 typst 目录下，你可以如下编译。

```sh
typst compile --root . typst/数学分析/main.typ typst/数学分析/main.pdf
typst compile --root . typst/高等代数/main.typ typst/高等代数/main.pdf
typst compile --root . typst/抽象代数/main.typ typst/抽象代数/main.pdf
typst compile --root . typst/考研背诵手册/main.typ typst/考研背诵手册/main.pdf
```
